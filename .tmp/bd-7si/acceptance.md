- A new module `learn/src/agents/learner-lesson-context.ts` exports a `LearnerLessonContext` type matching the design and a `loadLearnerLessonContext(sectionConceptIds: string[]): Promise<LearnerLessonContext>` function.
- `generateLessonStructuredV3` calls `loadLearnerLessonContext` once after `buildContext` and threads the result into the outliner, every prose writer, and every artifact builder; no agent calls `nmemo-client` directly.
- Given a learner with a `struggles_with` or `confused_by` fact whose `objectEntityId` is present in `section.conceptEntityIds`, the regenerated outline contains at least one prose item whose `intent` field mentions the concept name by name AND the prose markdown produced for that item contains the concept name.
- Given a learner whose `understands` fact for concept X has `confidence >= 0.6` and `last_fact_at >= 14 days ago`, the outline contains either a `FlashcardDeck` artifact item OR a remedial prose item targeting X.
- Given a learner with a `lacks_prerequisite` fact for prereq P needed-for concept C in this section, the outline contains a `Mermaid` or `ConceptMap` artifact whose spec mentions both P and C.
- When the learner has zero learner-facts touching any concept in `section.conceptEntityIds`, the orchestrator records `coldStart: true`, passes `undefined` (or an explicit cold-start sentinel) to each agent, and the resulting outliner+prose user prompts are byte-identical to the v0.3 baseline (snapshot test passes).
- If the platform `/api/learn/learner-facts` call returns 5xx, throws, or exceeds a 5 s timeout, the pipeline logs a single warning, proceeds in cold-start mode, and the section's `lessonStatus` reaches `ready` (it does NOT enter `error` for this reason alone).
- The artifact builder receives — through the existing `learnerState` parameter — extended fields `forgottenConcepts`, `confusions`, `missingPrereqs` when applicable, and these surface in the artifact spec sent to Opus (verifiable from the agent log line at `lesson-generator.ts` artifact-built log).
- The outliner system prompt gains a "## Personalisation" subsection; the prose writer system prompt gains a "## Personalisation" subsection. Cold-start regression test confirms no regression on canonical generation.
- A `console.log` line `[lesson-generator] learner-state: coldStart=<bool> facts=<n> confusions=<n> forgotten=<n> missingPrereqs=<n>` appears on every pipeline run, including the failure-fallback path (with all-zeros).
- Total HTTP traffic to `nmemo-client` per lesson generation is exactly one `getLearnerFacts()` call plus at most one `get_prerequisite_chain` call per distinct missing-prereq concept (cap of 5 prereq calls per lesson).
- Vitest (`learn/src/test/...` or wherever the existing learn-platform tests live) gains at least the 6 specific test cases in design §9; all pass on `npm test` from `learn/`.
- TypeScript build (`tsc --noEmit` or equivalent in `learn/`) passes with zero new errors; new types are exported from `learner-lesson-context.ts` and re-imported by `lesson-generator.ts`, `lesson-outliner.ts`, `lesson-prose.ts`.
- A learner with a confusion gets a regenerated lesson that visibly differs from the cold-start lesson (manual verification: regenerate same section twice — once with seeded confusion fact, once without — and diff `lessonBlocks`; diff is non-empty).
- The legacy single-shot path (`LEARN_LESSON_GENERATOR_LEGACY=1`) is left unchanged — it does not gain any learner-state awareness in this bead.
