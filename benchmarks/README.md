# Mnemo benchmark harness

Internal baselining cycle for Mnemo. See [`docs/benchmarks/plan.md`](../docs/benchmarks/plan.md) for the contract and [`docs/benchmarks/landscape.md`](../docs/benchmarks/landscape.md) for the survey behind the choice of these five.

## Layout

```
benchmarks/
├── _common/            # shared modules (client, judge, results, config)
├── dummy/              # self-test stub — proves the pipeline shape
├── longmemeval/        # (not yet) — nmemo-eue
├── corr2cause/         # (not yet) — nmemo-4fd
├── cladder/            # (not yet) — nmemo-9hp
├── locomo/             # (not yet) — nmemo-46r
├── graphrag/           # (not yet) — nmemo-q0e
├── cronqa/             # (not yet) — nmemo-9qq
└── results/            # JSON outputs per run (machine-readable)
```

Human-readable trend tables + cross-benchmark dashboard live in [`docs/benchmarks/results/`](../docs/benchmarks/results/) and are regenerated by `_common/results.py` after each run.

## Setup

```bash
cd benchmarks
uv sync
```

## Running a benchmark

Each benchmark exposes a single entry point invoked from the `benchmarks/` root:

```bash
uv run python -m dummy.run     # self-test (no real benchmark)
# uv run python -m longmemeval.run      # when nmemo-eue lands
# etc.
```

A run produces exactly one JSON file under `results/{benchmark}/runs/{date}-{sha7}.json` and regenerates the markdown trend tables.

## Model stack

- **System under test:** Haiku (per `feedback_haiku_first` — matches shipped pipeline).
- **Judge (LLM-as-judge):** Sonnet (`claude-sonnet-4-6`). Capable enough that judge variance doesn't swamp signal.
- **No cross-vendor comparator reruns.** Vendor numbers in `landscape.md` are reference context only.

Override defaults via env vars (see `_common/config.py`).

## Required environment

- Mnemo platform running on host (`pnpm dev` in `../platform/`); default `http://localhost:3000`.
- ML services on `:8000`, Postgres on `:5433`, Qdrant on `:6335`, Ollama on `:11434`. See repo root `make up`.
- `ANTHROPIC_API_KEY` set for the judge.
