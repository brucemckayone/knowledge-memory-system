The gap

Existing AI memory stores documents.
Not knowledge.

Three approaches to the same question — "what does this system remember?" One stores text. One stores state. One stores state, time, and cause.

Why two graphs, not one

State and cause are queried differently.

  • Backward tracing — "why is this true?" walks Graph C directly. No snapshot reconstruction.
  • Forward projection — "where are active dynamics heading?" also runs on Graph C. There's no way to do this from state alone.
  • Point-in-time queries — "what was true at time T?" stay on Graph S, where the bi-temporal filter is cheap.
  • Two separate indices. Performance, semantics, and access patterns all benefit.
docs/architecture/truth-graph/01-dual-graph-architecture.md §1

Entity resolution

Three-stage similarity, with thresholds.

A new mention's embedding (768-dim, plus 200-char context window) hits pgvector cosine against every known entity. The result lands in one of three buckets.

Aliases accumulate forever. Merges leave a row in entity_merges. Wrong merges are reversible.

Causal reasoner

A model-agnostic agent with seven tools.

The reasoner runs after extract — but only when the ingest is causally interesting. Three triggers:

  • the involved entities already have causal history
  • more than N facts arrived in this ingest
  • the source text contains causal language ("because", "led to", "after", "caused")

When it triggers, Claude Code (claude -p) connects to a local MCP server and reasons through the seven tools. No vendor SDK — any MCP-capable model works.

Contradictions

When sources disagree, the system says so.

A contradiction is a pair of facts with the same subject_id and predicate but different objects. They surface — they don't merge silently.

  • 200 unresolved right now in the running viz
  • Each one is either reconcilable (one fact is stale; expire it) or genuinely contested (both true at different times)
  • The reconciliation agent works through them; the human can intervene
  • This is what makes the system usable for compliance and research — it doesn't lie about consistency
Confidence decay

Old facts get less confident, on a curve.

C(t) = C₀ · exp(−t / S)
C₀
confidence at recording time
S
half-life — per predicate type
t
elapsed time since valid_at

Decay anchors on world time, not transaction time. Without bi-temporal storage this curve is wrong.

services/confidence-decay.ts
confidence(t) = C₀ · exp(−t / S)
confidence over time. some facts never decay. S = ∞. preferences fade. S = 365 days. a person's job changes more often. S = 90 days. today the system trusts each fact less, on its own schedule.

Adaptive Learn

The same primitives, with the learner as the subject.

Every other use case asks the graph to reason about a domain. This one asks it to reason about the person using it.

  • Learner understanding is stored as bi-temporal facts. Each quiz answer appends; old beliefs are never overwritten.
  • Confidence decay models forgetting. A topic untouched for a month surfaces as stale.
  • Root-cause tracing on Graph C: when a learner is stuck, walk backwards to find the prerequisite concept they missed.
  • Every tutor-chat turn writes through MCP, so agent writes are structured and reviewable.

Use cases

Six domains that fall out of the same primitives.

Project brain
Ingest Slack, git, Jira, meeting transcripts. Causal threads from "decision was made" to "ticket created" to "PR landed" to "incident". Pattern lifecycle catches recurring planning failures.
Personal KG
Email, chat, notes, reading. Beliefs that evolve via bi-temporal facts; decay surfaces forgotten threads; contradictions across sources get flagged.
Codebase intelligence
Code + design docs + commits + postmortems. The graph reasons about why a service is the way it is. Flags drift between docs and code.
Research synthesis
Papers, lab notebooks, experiment logs. Contradictions across the literature surface; causal claims trace back to the experiment that produced them.
Compliance / audit
Every fact has a source. The graph is the audit trail. Contradiction detection is the compliance check. Blast-radius queries are impact analysis.
Adaptive learning
The inversion — Mnemo reasons about the learner. Confidence decay models forgetting; causal tracing produces remediation paths. (This app.)

Compounding

Three primitives appear in every domain.

Fix a primitive once and every domain that uses it improves. That is the opposite of a feature catalogue.

every primitive reaches every domain. bi-temporal storage — retroactive corrections everywhere. source provenance — every regulated or research domain needs it. contradiction detection — multiple independent sources always conflict.
